# 배틀토드 — 패미컴 / NES

패미컴 / NES **배틀토드** 한글 번역 패치 프로젝트입니다. 전투와 다양한 스테이지 기믹을 결합한 액션 게임입니다.

> **배포본 · 2026-08-16**

## 다운로드 및 적용 방법

1. 아래 체크섬 또는 상세 안내와 일치하는 원본을 준비합니다.
2. [최종 배포 패치 다운로드](https://github.com/akuma815/nes-battletoads-kr-patch/releases/tag/release-20260816)에서 ZIP을 받아 모두 압축 해제합니다.
3. 원본 ROM 또는 ISO를 동봉 `apply.cmd`에 끌어다 놓습니다.
4. 생성된 한글판 파일의 SHA-256을 확인하고 실행합니다.

## 주의사항

- 일본판 원본 전용입니다.
- 본문 번역과 타이틀 등 실제 적용 범위는 동봉 안내를 확인하세요.
- 원본 게임·BIOS 및 패치가 적용된 게임 이미지는 포함하지 않습니다.
